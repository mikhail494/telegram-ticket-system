# ADR 0004: PolyForm Noncommercial Licensing

## Status

Accepted.

## Context

The repository is public for evaluation, learning, and noncommercial use while commercial rights remain reserved.

## Decision

License the project under PolyForm Noncommercial License 1.0.0 and retain commercial licensing as a separate permission.

## Consequences

The code is publicly visible but is not OSI-approved open source. Commercial users need to contact the repository owner for permission or a separate license.
